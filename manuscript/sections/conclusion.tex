Threshold batching changes the relevant active-set complexity from the number
of admitted coordinates to the number of complete exposed faces.  The
Stieltjes order structure makes every admitted batch support-safe; the
block-Cholesky/Chebyshev argument limits the number of face rebuilds to
$\softO(1/\sqrt\alpha)$; and nearly-linear supplied-face SDD solves convert
that depth bound into $\softO(1/(\rho\sqrt\alpha))$ fully charged RPPR work.
An approximate inner face is already a sufficient PPR envelope, so the
strict two-stage handoff yields the desired point-source
$\softO(1/(\epsppr\sqrt\alpha))$ guarantee without carrying momentum or a
dynamic inverse across support changes.

The grounded electrical-flow dual makes the algorithmic interface explicit:
the PageRank residual is a dual vertex-constraint slack, the boundary reporter
is a local separation oracle, and a terminal face is a dual-feasible
certificate.  Fenchel duality itself is classical and is not claimed as a
standalone contribution.  Its role here is to expose why support discovery is
a constraint-generation problem; the new result is that threshold batching
controls the number of complete local separation-and-rebuild rounds.

The result is complete in its stated exact-real randomized model, but its
scope matters.  The random SDD solver is an existing primitive, not the
paper's novelty; deterministic support safety comes from the checked
residual interface.  General sparse sources do not inherit the same additive
work bound for free.  Deterministic finite-precision and coefficient-bit
complexity, and a practical persistent implementation that avoids rebuilding
even the bounded number of faces, remain open.  These are now refinements of
an established arbitrary-graph point-source theorem rather than gaps in the
underlying two-stage existence argument.
