The PageRank literature uses the same letters for several different walk
operators, matrix scalings, coordinates, and accuracy criteria.  We therefore
separate three layers of notation: an undecorated reference formulation used
throughout this paper, a conversion dictionary for prior work, and
algorithm-scoped symbols introduced only where they are needed.  In
particular, a bare \(\varepsilon\) never denotes more than one accuracy notion.

\paragraph{Lazy-walk fixed point.}
Let
\[
    P:=AD^{-1},
    \qquad
    P_{\rm L}:=\frac{I+P}{2}.
\]
Thus \(P\) is the non-lazy column-walk operator and \(P_{\rm L}\) is its lazy
version; we do not use \(W\) for either matrix.  Multiplying
\(Qx^0=b\) by \(D^{1/2}\) shows that the vector
\(\pi=D^{1/2}x^0\) is equivalently characterized by
\begin{equation}
    \pi
    =
    \alpha s+(1-\alpha)P_{\rm L}\pi.
    \label{eq:reference-lazy-ppr}
\end{equation}
Because \(P_{\rm L}\) is column stochastic, \(\pi\geq0\) and
\(\inner{\one}{\pi}=1\).  The normalized optimization variable and the mass
coordinate are related by
\begin{equation}
    x^0=D^{-1/2}\pi,
    \qquad
    \pi=D^{1/2}x^0.
    \label{eq:reference-coordinate-map}
\end{equation}

\subsection{Output accuracy and computable certificates}
\label{subsec:accuracy-and-certificates}

For an approximate normalized solution \(\widehat x\), write
\(\widehat\pi:=D^{1/2}\widehat x\).  The document-scoped semantic PPR target is
\begin{equation}
    \norm{D^{-1}(\widehat\pi-\pi)}_\infty
    =
    \norm{D^{-1/2}(\widehat x-x^0)}_\infty
    \leq\epsppr.
    \label{eq:ppr-semantic-accuracy}
\end{equation}
This is an output statement, not an algorithmic activation rule.

\begin{proposition}[A sufficient scaled-system certificate]
\label{prop:scaled-system-certificate}
Every \(\widehat x\in\R^n\) satisfies
\begin{equation}
    \norm{D^{-1}(\widehat\pi-\pi)}_\infty
    \leq
    \frac{1}{\alpha}
    \norm{D^{-1/2}(Q\widehat x-b)}_\infty.
    \label{eq:scaled-system-certificate}
\end{equation}
Hence
\(\norm{D^{-1/2}(Q\widehat x-b)}_\infty\leq\alpha\epsppr\)
is sufficient for \cref{eq:ppr-semantic-accuracy}.
\end{proposition}

\begin{proof}
Set
\[
    B:=D^{-1/2}QD^{1/2}
      =\frac{1+\alpha}{2}I
       -\frac{1-\alpha}{2}D^{-1}A.
\]
The matrix \(B\) is a nonsingular \(M\)-matrix, so \(B^{-1}\geq0\).
Moreover, \(D^{-1}A\one=\one\), and therefore
\(B\one=\alpha\one\).  It follows that
\(\norm{B^{-1}}_\infty=\norm{B^{-1}\one}_\infty=1/\alpha\).  Using
\(Qx^0=b\) gives
\[
    D^{-1}(\widehat\pi-\pi)
    =
    B^{-1}D^{-1/2}(Q\widehat x-b),
\]
which proves the claim.  This is the same scaling behind the local
certificate used by \citet[Lemma~2.2]{huang2025accelerated}.
\end{proof}

The certificate above fixes neither a residual sign nor a repository-wide
stopping rule.  Each algorithm below defines its maintained residual, its
evaluation schedule, and whether its inequality is strict or non-strict.  The
accuracy namespace is:

\subsection{Degree-weighted local work and optimization diagnostics}
\label{subsec:source-work-and-stopping}

The common computational unit is an adjacency-list entry.  A coordinate push
at \(u_t\) has cost \(d_{u_t}\), so a coordinate method is charged
\begin{equation}
    \operatorname{Work}_{\rm coord}(T)
    :=
    \sum_{t=0}^{T-1}d_{u_t}.
    \label{eq:coordinate-degree-work}
\end{equation}
For a batch proximal method with extrapolated point \(y_k\) and next iterate
\(x_{k+1}\), the symmetric source measure is
\begin{equation}
    \operatorname{work}_k
    :=
    \vol(\supp(y_k))
    +
    \vol(\supp(x_{k+1})),
    \qquad
    \operatorname{Work}(N)
    :=
    \sum_{k=0}^{N-1}\operatorname{work}_k.
    \label{eq:source-degree-work}
\end{equation}
Both measures charge \(d_i\) whenever coordinate \(i\)'s neighborhood is
scanned; they differ only in the set of coordinates scanned at one iteration.
Iteration count and wall-clock time do not replace this work measure.

For completeness, the experiments of
\citet{fountoulakis2026complexity} use the unit-step proximal-gradient map
\begin{equation}
    T_{\alpha,\rho}(x)
    :=
    \prox_{g_\rho}\bigl(x-\nabla f(x)\bigr),
    \qquad
    r_{\rm pg}(x)
    :=
    \norm{x-T_{\alpha,\rho}(x)}_\infty,
    \label{eq:source-fixed-point-residual}
\end{equation}
and stop when \(r_{\rm pg}(x_k)\leq\epspg\).  This is distinct from the
source's theoretical objective target
\(F_\rho(x_N)-F_\rho(x^\star)\leq\epsobj\); the source prints both with the
same epsilon glyph, whereas we do not.

We call a method \emph{local} when its degree-weighted work can be bounded in
terms of the seed-local output scale and problem parameters, without an
unavoidable dependence on \(n\) or \(m\).  An active-set average such as
\(T^{-1}\sum_{t<T}\vol(S_t)\) is always written explicitly; it is never
denoted by the same symbol as the smaller-side volume used in conductance.

\subsection{Notation discipline for algorithm-specific objects}
\label{subsec:source-auxiliary-notation}

The undecorated symbols \(Q\), \(P\), \(x\), \(\pi\), \(\rho\), and
\(\vol\) retain the meanings above.  Alternative matrix scalings carry a
subscript, residuals are defined by a formula before their sign is used, and
condition numbers are written as \(L/\mu\) when a paper uses \(\kappa\) for a
different quantity.  Our canonical volume is
\(\vol(S)=\sum_{i\in S}d_i\), without an added \(|S|\).  Likewise,
\(\partial S=\mathcal N(S)\setminus S\) is a vertex boundary; an edge
boundary is written explicitly as \(E(S,V\setminus S)\).  Decorated internal
or matrix-access volumes are introduced only in comparisons that need them.

Instance notation is also local to the result that uses it.  A star is written
\(K_{1,m}\), with center \(c\) and leaf set \(L\); a center-seeded star uses
\(s=e_c\).  An endpoint-seeded path is written \(P_{m+1}\) with seed
\(s=e_1\).  Breakpoints, margins, momentum factors, evolving-set averages,
and stage counters from prior papers are not part of the global problem
definition and are defined only in the corresponding analysis.
