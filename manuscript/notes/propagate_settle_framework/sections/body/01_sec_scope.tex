This note uses two note-scoped loads.  The unregularized problem has
$\ell=b$.  For RPPR, positivity turns the active KKT equations into a shifted
linear system with
\begin{equation}
 \ell_\rho:=b-\alpha\rho D^{1/2}\one.
 \label{eq:shifted-load}
\end{equation}
No conversion between $\rho$ and $\epsppr$ is asserted.  The repository-wide
residual convention remains open.  All residual displays in this note state
their sign explicitly.

The empirical benchmark charges $1+d_u$ per executed row operation, whereas
the shared theoretical convention charges $d_u$ per adjacency scan.  Define
\begin{equation}
 \operatorname{cvol}(U):=\sum_{u\in U}(1+d_u).
 \label{eq:charged-volume}
\end{equation}
Because the shared graph is connected and has at least two vertices,
\begin{equation}
 \vol(U)\leq\operatorname{cvol}(U)\leq2\vol(U).
 \label{eq:charged-volume-equivalence}
\end{equation}
Thus the two work units agree up to an absolute factor, while
$\operatorname{cvol}$ makes the empirical mapping literal.
