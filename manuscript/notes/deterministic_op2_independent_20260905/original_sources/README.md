# Original audited TeX sources

These three files are byte-identical to the original proof sources in the ZIP.
The `.txt` suffix identifies them as preserved historical source, not active
repository LaTeX entry points. To compile them independently, copy them outside
`manuscript/notes`, remove only the final `.txt` suffix, and compile
`deterministic_conjecture2.tex` twice with `pdflatex`.

The new `main.tex` uses shared repository notation; these historical sources
retain their original symbols and macros. See the parent README for the mapping.
