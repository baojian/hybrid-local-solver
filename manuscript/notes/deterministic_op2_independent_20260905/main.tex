\begin{abstract}
This note records a deterministic continuation algorithm combining accelerated
projected corrections, exact sparse threshold reporting, and certified stage
repair. The original proof establishes an accelerated objective rate and a
separate bound on cumulative scanned degree volume, yielding fully charged
$\widetilde O(1/(\rho\sqrt\alpha))$ work for the second conjecture in the
problem-definition note. We give the algorithm, the essential proof chain,
and an explicit map to the archived full proof and implementation. Acceleration
itself is standard; the additional argument concerns its compatibility with
local graph access and a safe sparse output.
\end{abstract}
