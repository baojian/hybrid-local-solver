\begin{abstract}
This note proves three class-complexity statements for Problem~1, personalized
PageRank, on a single instance --- the centre-seeded star $K_{1,m}$ with
$m=\floor{1/(8\epsppr)}$ --- under one primitive, the fully charged work
model, one output representation, and the semantic PPR guarantee. Monotone
one-hop push, the class that keeps the residual nonnegative, requires
$\Theta(1/(\alpha\epsppr))$ charged work;
allowing signed \emph{steps} while keeping the residual nonnegative buys
nothing. Signed one-hop relaxation, which drops residual nonnegativity but
keeps dissipativity $\omega\in(0,2)$, requires
$\Omega(1/(\sqrt\alpha\,\epsppr))$, matched by a member up to a factor
$\log(1/\alpha)$ that measurement, but not yet proof, removes. Elimination,
which drops dissipativity, solves the instance exactly in
$\Theta(1/\epsppr)$. Thus the proved lower-bound scales improve by a factor
$\sqrt\alpha$ at the two substantive class transitions; an exact matching
statement for signed relaxation remains open.

The monotone bound rests on a single potential, the relative unsettled value
at the seed, whose two properties are exact and graph-free: it moves only at
seed-based operations, for either sign of the step, and nonnegativity of the
residual caps each seed step multiplicatively. This yields a general-graph
statement with no instance constant. The signed bound replaces the order
argument by energy: dissipativity caps the fast spectral mode, a centre
relaxation moves the slow and fast modes by equal magnitudes, and the seed
coordinate must travel a constant distance, so each operation can advance it
by at most $2\sqrt{\alpha(1+\alpha)}$ --- pathwise, so randomization is not
exempt. Output post-processing is handled symmetrically for both bounds
through one-hop output maps of bounded column mass. Those maps are an
auxiliary oracle extension: their construction and application are not free
in Problem~1's fully charged model. A zero-\emph{push} threshold delimits the
range in which a scan-work lower bound can live, while the sparse-output cost
remains charged.

The note also records what the ladder does \emph{not} say. The signed bound
is a class statement, not an information barrier: elimination is
asymptotically faster than every member of that class on the same instance by
at least an $\Omega(1/\sqrt\alpha)$ factor. Thus the result gives no support
to $1/(\sqrt\alpha\,\epsppr)$ as a necessary cost of the semantic problem.
Two items are stated as open: the general-graph
terminal bound for output maps near the escape threshold, and whether any
bounded-seed-degree family forces the signed bound. Provenance, per-statement
status, a verification appendix, and an auditor's checklist are in the final
section.
\end{abstract}
