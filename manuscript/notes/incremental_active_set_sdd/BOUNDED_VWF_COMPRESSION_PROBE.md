## The source compression dependency still to replace

Use Chen–Peng–Wang arXiv:2105.14629v2, particularly Definition 3.2,
PDF p. 14; Fact 7.2 and Lemmas 7.6–7.7, pp. 35–36; Algorithm 8 and
the proof of Lemma 6.4, pp. 36–37. Definition 3.2 was visually checked.
Recheck the full inequalities in Lemma 7.7 before composing a new theorem.
The source's logarithmic bin count uses a bounded nonzero breakpoint
ratio. A known bound on the original energy and a safe graph-edge deletion
rule do not themselves bound those recursive breakpoints.

The following is a **Conditional probe**, not an implemented algorithm or
an imported theorem. For a VWF whose derivative is nondecreasing, concave
and eventually constant, write its Bregman part at zero as

    B_f(x) = sum_s q_s B_s(x),  q_s >= 0,
    B_s'(x) = min(x,s)-min(0,s),  B_s(0)=0.

Let C=sum q_s bound its initial curvature and suppose relevant evaluations
are in `[-R,R]` intersected with the source domain. For any two split points,

    |B_s'(x)-B_t'(x)| <= |s-t|,
    |B_s(x)-B_t(x)| <= R*|s-t|.

The first inequality follows by integrating the difference of the two
curvature indicators from zero to x; its support has length |s-t|.
Thus moving every split with |s|<tau to **zero, retaining its curvature
coefficient**, changes the function by at most C*R*tau on that box, while
preserving its value and derivative at zero and the VWF shape. Deleting
those terms is not equivalent: a split just below zero can contribute a
large quadratic on negative fields. Handle the zero split explicitly;
do not divide s by its rounded value when both are zero.

After this snapping step, use the source's constant-factor geometric
compression only on the remaining nonzero splits. On a bounded range the
candidate bin count is O(log(R/tau)); a grid can be generated by exact
multiplication and scanned with the sorted splits, avoiding a unit-cost
real logarithm assumption. Large positive splits beyond R have the same
quadratic behavior within the box, while splits below -R contribute zero
there. Any use of that truncation is conditional on a proved evaluation
domain, not just the optimum's location.

If the snapped function F_s has uniform error xi and an exact compression
F_c satisfies `2*F_s(x/2)<=F_c(x)<=F_s(x)` on the required domain, then
subtracting xi from F_c gives

    2*F(x/2)-3*xi <= F_c(x)-xi <= F(x).

This suggests an additive-error version of the source embedding. Establish
the exact function and graph scaling, signed fields, f(0) convention and
summed error before claiming a recursive solver. Changes of constant
approximation factors must be reflected in the source work recurrence.

## Falsifiable next work

A useful **candidate sublevel bound to formalize and audit** is available
for the original capped physical objective. With lambda=eps_appr/2 and
U=1/bar_alpha, each nonseed capped term obeys q_i(x)>=lambda*x for x>=0.
At the seed, q_v(x)-lambda*x has minimum at least -1/(2*bar_alpha):
its quadratic linear coefficient is `1-lambda*(d_v-1)<=1`, and its
post-cap slope is nonnegative. The edge energy is nonnegative, so

    E_cap(x) >= lambda*sum_i x_i - 1/(2*bar_alpha).

Consequently a feasible nonpositive-energy point has
`sum_i x_i <= 1/(2*bar_alpha*lambda)`. More generally a known energy
upper bound gives a known coordinate bound. This controls feasible
original iterates, not automatically every accelerated center or recursive
proximal objective. Extrapolation of two bounded feasible iterates is
bounded, but proving the required energy bounds and tracing added linear
terms and component coercivity remain explicit obligations. Do not assume
that a proximal linear shift preserves every individual positive tail slope.

1. Implement the small-split-to-zero operation and audit complete affine or
   quadratic intervals, including negative fields and a zero split. Prove
   its additive error and combine it carefully with the source geometric
   compression. Count every input event, bin, copy and recovery record.
2. Supply an upper bound on curvature C and on **all necessary evaluation
   fields**, including shifted residual instances and accelerated extrapolated
   points. The known box for the original optimum is insufficient by itself.
   Source leaf elimination, addition, shifts and compression may preserve
   useful curvature bounds; verify each operation instead of assuming it.
3. Connect the additive budget to a computable stopping policy. When the
   original C(w) exceeds threshold t, the gap is strictly larger than
   `bar_alpha*t/(1+gamma)`. This is a known minimum gap for a still-needed
   refinement call. The certificate itself has a charged scan; count it
   once per refinement and later address cumulative support expansions.
4. Keep initial parameter scales distinct. A simple proposed shortcut is:
   query d_seed; return zero if eps_appr*d_seed>=1; otherwise, if
   gamma<=eps_appr*d_seed, the physical vector e_seed/d_seed has seed
   residual zero and every nonseed residual at most gamma/d_seed<=eps_appr.
   This needs only the seed degree. If confirmed and used, remaining cases
   have gamma>eps_appr, so an unwanted log(1/(1-alpha)) input-scale factor
   can be bounded by log(1/eps_appr). This shortcut is not yet an implemented
   or formally promoted result of block 5.

Even a complete parameter-uniform supplied-graph constrained solver would
leave the general local construction and cumulative supplied-graph work
open. Keep that distinction central and do not claim OP3 from small final
support, a single local certificate or the present special cases.
