\section{The first bounded-cycle quotient obligations}
\label{sec:op3-quotient-cycle-frontier}

A natural next restricted target is an original twin quotient with a few
cycles. The following combinatorial bound is \statusproved{} as a proof
draft, but the full weighted cyclic numerical composition remains
\statusopen. Original type partitions in its finite audit are validators,
not preprocessing available to a local algorithm.

\begin{lemma}[A cycle budget for frontier type groups; \statusproved]
\label{lem:op3-quotient-cycle-frontier-budget}
Let the connected canonical original-type quotient $Q$ have cycle rank
$r$. Let its connected active induced subgraph $H$ have rank $r_S$.
Every represented nonseed type is complete, while the source type $R$
is complete or its initial singleton. For a new, unrepresented type $T$,
let $\ell_T$ count its active quotient parents. Then
\[
 \sum_{T\notin H}(\ell_T-1)_+\leq r-r_S.
\]
Consequently at most $r-r_S$ new types have two or more active parents,
and each new type has at most $r-r_S+1$ active parents. Every known
inactive physical vertex with more than $r-r_S+1$ distinct active type
parents is therefore a remaining source twin. Its degree and the cached
source-adjacency bit justify the source gate
\eqref{eq:op3-twin-tree-exceptional-gate} without reading its row.

Group all known inactive vertices with at least two parents by their
current active-type parent set, allowing unequal original degrees in a
group heap. The number of nonempty such groups is at most $r-r_S+1$;
the final $1$ can be removed if the source type is complete.
\end{lemma}
\begin{proof}
Adjoin every new type with $\ell_T\geq1$ to $H$, retaining only its edges
to $H$ and no edges between newly adjoined types. This connected subgraph
of $Q$ has cycle rank
\[
 r_S+\sum_{T:\,\ell_T\geq1}(\ell_T-1)\leq r.
\]
Every summand is nonnegative. This proves the first assertions, including
the high-parent source classification: the only already represented type
with unadmitted members is $R$. All unadmitted members of a given original
type share their active parent set and original degree. A current parent-set
group may combine several types, but cannot split one type. There are at
most $r-r_S$ new multi-parent types and at most one additional incomplete
source type. The group bound follows. Internal clique adjacency can add
$R$ itself as a parent of its missing members; it does not affect the
cycle argument for new quotient types.
\end{proof}

\begin{proposition}[Two parents no longer identify the source type;
\statusproved]
\label{prop:op3-five-cycle-source-type-ambiguity}
The tree-only rule ``two distinct active type parents imply missing source
twins'' is false on a quotient with one cycle, even at a legal strict
positive physical prefix and with the same original candidate/source degree.
\end{proposition}
\begin{proof}
Use the original five-cycle $0$--$1$--$2$--$3$--$4$--$0$, source $0$,
$\alpha=1/3$, $\gamma=1/2$, $\lambda=1/64$ and $\kappa=1/128$.
Every canonical type is a singleton. Starting from $\{0\}$, the fixed
old-face gates admit $\{1,4\}$ together and then $\{2\}$ from the heap
at $1$. The two relevant pre-admission residuals are $31/128$ and
$27/448$, both strictly above
$(\lambda+\kappa)d=3/64$.
At $S=\{0,1,4,2\}$ the exact restricted values are
\[
 x_0=\frac{1825}{3344},\quad x_1=\frac{417}{3344},\quad
 x_4=\frac{101}{836},\quad x_2=\frac{13}{836}.
\]
They are positive and every active original residual is $1/32$.
The remaining vertex $3$ has active parents $2,4$ and degree $2=d_0$,
but is not a source twin. Its true residual is $3/44$, whereas the
incorrect source-twin formula gives
\[
 2x_0-1+2\lambda=\frac{821}{6688},\qquad
 \frac{821}{6688}-\frac3{44}=\frac{365}{6688}>0.
\]
This is an identity and classification obstruction. Both gates are positive
at this particular prefix, so it is not a wrong terminal-output example.
\end{proof}

\paragraph{Measured scope and next falsifiable construction.}
\path{quotient_cycle_frontier.py} checks the cycle-excess inequality and
physical parent-group counts on every connected active quotient subset
of the recorded small graph family. Complete and singleton source classes
are both represented. These broader combinatorial subsets need not be
reachable positive faces. Its separate five-cycle computation verifies the
three actual positive prefixes above. The full audit uses 258 original graph blow-ups and checks 6,463
cycle-excess inequalities, 36,824 complete/incomplete-source frontier
states and 196,027 original parent quotas. It records 8,212 high-parent
source identifications. The parameters and source hashes are in
\path{QUOTIENT_CYCLE_FRONTIER_AUDIT.json}.

For a supplied rank bound $r$, the lemma suggests keeping all ordinary
one-parent heaps in the weighted tree reporter, explicitly querying the
at most $r+1$ small exceptional parent sets, and using the source identity
only after the parent-count test certifies it. This still needs a paid
parent-set refinement and grouping construction; repeatedly copying a
large source parent set would lose the intended work bound.
A single-cycle numerical extension must also maintain the weighted cycle
correction, handle the once-only source multiplicity change and its
physical contrast, and restore reporters before any original gate query.
The existing unweighted unicyclic theorem cannot be imported without
checking these weighted load and update interfaces. A fully charged local
one-cycle quotient construction is the next bounded target; no such fast
upper bound is asserted in this section.
