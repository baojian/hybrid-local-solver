# local_solver_oracle_hierarchy

This standalone note separates adjacency access from the computational and
representation restrictions used in local-solver lower bounds. Its ambient
information problem is single-seed, source-aligned PPR on an undirected graph
under adjacency-list revelation. The note-scoped semantic output condition is

```text
||D^(-1/2) (x_hat - x^0)||_infinity <= eps_ppr,
```

for an explicit word-RAM sparse vector. It does not select an implementation
stopping rule or identify `eps_ppr` with APPR, RPPR, objective-gap, or
proximal-residual tolerances. A separate exact-algebraic endpoint-path task
below explicitly adopts the sufficient certificate
`||D^(-1/2)(b-Q*x_hat)||_infinity <= alpha*eps_ppr`; that note-scoped choice
does not resolve the repository-wide residual decision.

The execution ledger records eleven resources separately:

```text
(adjacency exposure, adjacency-query adaptivity, external interaction,
 preprocessing, online control arithmetic, row recurrence, response
 construction/application/query computation, persistent memory, transient
 workspace, intermediate materialization, emitted replies/final output).
```

Response-query computation and emitted words are distinct. Scratch space is
charged even when freed between calls. `RowRec` permits momentum, conjugate
directions, restarts, masking, and charged exposed-row actions. A
graph-dependent preconditioner not generated by those actions is response
state: construction or preprocessing, storage/workspace, and application must
be charged. `MatRestrict` is an independent representation property.

For the still-open computational target, the note defines the final charged
degree volume

```text
nu_fin := vol(S_fin) = sum_{i in S_fin} d_i.
```

This is distinct from the vertex set `V` and does not hide repeated reads or
other ledger costs. The target is a budgeted `RowRec` lower bound at
`Omega_tilde(nu_fin / sqrt(alpha))` versus a fully charged response algorithm
at `O_tilde(nu_fin)` on an identical task.

For degree-normalized PPR error, the note proves:

- seed-connectedness and degree volume at most `1 / eps_ppr` for the exact
  superlevel core;
- a matching `Theta(1 / eps_ppr)` explicit-output bound using a center star;
- killed-capacity packing for internally disjoint seed corridors;
- the `M * L = O(1 / eps_ppr)` obstruction at diffusion depth
  `L = Theta(1 / sqrt(alpha))`;
- exact finite-path completion sensitivity at no more than the output scale;
  and
- the constant-rank Woodbury formula for degree-preserving hidden-edge swaps.

The note also proves six narrow model results:

- After an SPD system is completely exposed, a recurrence with graph-dependent
  inverse construction, encoding, and application all free can solve in one
  residual step. Thus those three capabilities cannot all be free in a
  recurrence-iteration or condition-number lower bound. The lemma does not
  make each restriction independently necessary and is not an access, memory,
  preprocessing, or output lower bound.
- On an auxiliary endpoint-path task with realized stopping time
  `tau_stop <= K`, every exact-materialized implementation writes
  `Omega(tau_stop^2)` algebraic cells; this materialization coordinate is
  tight. One non-prefetching append-only `LDL^T` response has linear
  exact-cell costs in `tau_stop`, with constant transient workspace. The
  theorem separates external interaction from algorithmic adjacency
  adaptivity and gives no adaptivity lower bound.
- Under the concrete budget
  `(B_pre,B_resp,B_mem) = (0,floor(sqrt(nu_n)),32*nu_n)` on an endpoint path,
  exact unpreconditioned CG is admissible and uses no response allowance.
  With `alpha = n^(-4)`, it solves the same exact full-vector task in
  `O(n^2)` charged work, while `nu_n / sqrt(alpha) = Theta(n^3)`. Momentum,
  Jacobi scaling, and the positive response budget cannot restore a lower
  bound already contradicted by this class member. Equations
  `eq:path-cg-resource-vector` and `eq:path-ldl-resource-vector` report all
  eleven coordinates for the two same-task implementations.
- In the surviving fully exposed, fixed-support exact regime
  `alpha = n^(-2)`, for every positive diagonal `M`,
  `h=M^(-1/2)b_n` is cyclic for the symmetric scaling
  `T=M^(-1/2)Q_nM^(-1/2)`. Exact polynomial, Chebyshev, scalar-momentum, and
  fixed-positive-diagonal Krylov methods, plus polynomial preconditioning
  within `DiagSpecPoly(0)` with every underlying `T` application counted, need
  degree at least `n-1`. In the explicitly named spectral-atom subclass,
  correcting `r <= floor(sqrt(nu_n))` charged eigenmodes still leaves degree
  at least `n-r-1`, so full-vector recurrence work is `Omega(n*nu_n)`. This
  work conversion uses the named subclass's defining full-vector application
  charge; the degree bound alone does not give `Omega(n*nu_n)` for a supported
  growing-prefix Krylov execution. Such executions need a separate
  cumulative-support proof and are excluded here. The result does not turn an
  arbitrary response-work budget into a rank bound and does
  not cover nonlinear, adaptive, rational, or implicit response maps.
  `eq:surviving-named-subclass-resource-constraints` reports every ledger
  coordinate for the named class, and
  `eq:surviving-path-cg-resource-vector` gives the matching exact-CG costs.
- For the actual sparse residual-certificate task on the endpoint path with
  `n >= 8`, `alpha=n^(-2)`, and `eps_ppr=1/10`, the named exact-cell
  `CertPrefixPoly` class has a constant-work counteralgorithm. Its five
  normalized coordinates are
  `alpha*(60,40,24,12,4)/11`; the six possibly nonzero scaled residuals are
  `alpha*(1-50*alpha,1-41*alpha,1-25*alpha,1-13*alpha,
  1-5*alpha,1-alpha)/11`, hence are strictly below `alpha/10`.
  Endpoint Krylov triangularity makes this vector a degree-four polynomial in
  `Q` applied to `b`, evaluable with four constant-prefix row actions. A fully
  charged five-row append-only `LDL^T` response returns the same sparse output
  in constant work. Equations `eq:certificate-prefix-poly-resource-vector`
  and `eq:certificate-path-response-resource-vector` report all eleven
  coordinates. This refutes product work for that sparse-certificate class,
  even with its realized final exposed volume `nu_fin=vol([6])=11`,
  not the exact full-vector `DiagSpecPoly(r)` theorem or the ordinary-CG
  trajectory imported from `evolving_support_cg`.
- Tightening that same actual certificate to `eps_ppr=1/(10n)` forces every
  accepted sparse list to contain all `n` path coordinates, so
  `nu_fin=2(n-1)`. It still does not force product work under the broad
  supported-prefix semantics. Exact exposed-row actions and scalar
  cancellations generate singleton coordinate directions; after the far
  endpoint is known, a fixed degree-six spatial profile is synthesized and
  verified in `Theta(n)` recurrence/control work with `C_mat=0`. A fully
  charged append-only path response answers the identical task in
  `Theta(n)` work, whereas `nu_fin/sqrt(alpha)=Theta(n^2)`. Equations
  `eq:tight-sparse-basis-resource-vector` and
  `eq:tight-path-response-resource-vector` report all eleven coordinates.
  The delayed fixed-profile combinations are recurrence work; a projected
  tridiagonal solve, factor, or graph-dependent inverse would instead be
  response work and is not hidden in this construction.

The path theorem is exact real-RAM/algebraic-cell only. It supplies neither
word/bit complexity nor a finite-precision, precision-robust, or
`nu_fin / sqrt(alpha)` computational separation. It is a weaker auxiliary
representation analogue, not a closed version of the central problem. The
companion response note's comb proposition is used only as a memory/rank
stress test: a full harmonic bank is quadratic and every rank-deficient bank
has constant energy error for fixed `alpha < 1`, but implicit tree response
remains allowed.

The CG counteralgorithm defeats this fully exposed endpoint-path candidate
when `n = o_tilde(1 / sqrt(alpha))`. More generally, the restriction
`n = Omega_tilde(1 / sqrt(alpha))` is necessary for a fixed-support
exact-system product lower bound against CG only after the `n`-dimensional
system has been exposed with `O(nu)` representation/matrix--vector cost and
enough vector memory. It does not govern every approximate local
support-discovery task or transfer automatically to finite precision. In the
surviving regime, `thm:surviving-path-polynomial-obstruction` proves a tight
work obstruction only for the named full-vector polynomial/diagonal and
charged spectral-atom subclass, not for the full `RowRec` framework. On the
actual sparse certificate task, `thm:five-site-supported-prefix-counteralgorithm`
shows that supported polynomial generation alone is insufficient: a
degree-four polynomial spends the allowed residual slack across six local
rows and stops in constant work even though literal exact CG takes all `n`
steps. At the tighter `eps_ppr=1/(10n)`, the constant-prefix escape disappears
but `thm:tight-certificate-sparse-basis-counteralgorithm` gives a different
linear-work escape through singleton coordinate directions and delayed fixed
profile synthesis. The result is exact-cell and path-specific; it is not a
finite-precision algorithm or a statement about a narrower Galerkin,
trajectory, or full-prefix-materialization class.

The optimal variable-`alpha` adjacency-query complexity and bounded-overlap
killed-Green influence packing also remain open. No universal
`Omega(1 / (eps_ppr * sqrt(alpha)))` adjacency-query bound is claimed.
