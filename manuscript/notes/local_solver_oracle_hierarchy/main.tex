\title{Adjacency Access Is Not a Solver Class:\\
An Oracle and Representation Hierarchy for Local PageRank Lower Bounds}
\author{Baojian Zhou\\
\small Working research note for \texttt{hybrid-local-solver}}
\date{August 2026}

\begin{document}
\maketitle

\begin{abstract}
Adjacency-list access is a clean model of how a local graph algorithm learns
its input, but it is too broad to distinguish local recurrence from persistent
elimination.  After exposing a subgraph, an adjacency-access algorithm may run
coordinate descent, conjugate gradients, exact Gaussian elimination, an SDD
solver, or a dynamic Schur data structure.  Consequently an algorithm-specific
star or spider lower bound cannot be promoted to every adjacency-access local
solver without an additional computational or representation restriction.

This note proposes a capability ledger for the project and proves two
information-level facts for degree-normalized additive PPR error.  First, the
exact superlevel set is connected to the seed and has degree volume at most
$1/\varepsilon$; a center-seeded star gives the matching explicit-output
lower bound.  Thus the word/output complexity is
$\Theta(1/\varepsilon)$, with no polynomial dependence on $1/\alpha$.
Second, an $\alpha$-killed capacity argument proves that internally disjoint
seed corridors obey a packing inequality.  At diffusion depth
$L=\Theta(1/\sqrt\alpha)$, $M$ such corridors can coexist with an
$\varepsilon$-visible normalized PPR coordinate only when
$ML=O(1/\varepsilon)$.  This formally explains why the project's spider gives
product work only after a persistent-support rescan restriction is imposed.

The ambient adjacency class allows arbitrary persistent computation on
exposed information.  Within it we distinguish materialized repeated
restricted solves, local linear-span or bounded-recurrence methods, and
persistent response methods that store elimination or Schur summaries.  We
give an exhaustive execution ledger that separately charges adjacency
exposure and adaptivity, external interaction, preprocessing, online control,
recurrence, response computation, persistent and transient memory,
intermediate materialization, and emitted replies/output.  Two exact boundary
results follow.  After complete exposure, an inverse oracle whose construction,
encoding, and application are all free collapses a residual recurrence to one
exact step, so that class cannot support a recurrence-iteration or
condition-number lower bound.  Conversely, on one auxiliary online
endpoint-path task stopped at $\tau_{\rm stop}\leq K$, every exact-materialized
implementation writes $\Omega(\tau_{\rm stop}^2)$ algebraic cells, while one
append-only tridiagonal response uses linear work and space in
$\tau_{\rm stop}$.  This exact-arithmetic result is only a weaker
representation analogue; it is neither word/bit complexity nor the desired
charged-volume recurrence-versus-response separation.  We also derive the exact
low-rank Green-function formula for a degree-preserving hidden edge swap and
isolate a bounded-overlap influence-packing lemma as the central missing
statement for stronger oracle lower bounds.  Finally, under the concrete
budget $(0,\lfloor\sqrt{\nu_n}\rfloor,32\nu_n)$, exact
conjugate gradients defeats the fully exposed, fixed-support path product
candidate when
$\alpha=n^{-4}$: it uses $O(n^2)$ charged work while
$\nu_{\rm fin}/\sqrt\alpha=\Theta(n^3)$.  More generally, after an
$n$-dimensional exact SPD system has been fully exposed with
$O(\nu_{\rm fin})$ representation and matrix--vector cost and enough vector
memory, a product-scale lower bound against a class containing CG requires
$n=\widetilde\Omega(1/\sqrt\alpha)$.  This condition is not asserted for an
approximate local support-discovery task.  In the surviving choice
$\alpha=n^{-2}$, endpoint cyclicity gives a matching
$\Omega(n\nu_n)$ recurrence obstruction for a named exact \emph{full-vector}
subclass containing
polynomial/Chebyshev/momentum methods, positive-diagonal PCG, polynomial
preconditioning with every underlying $T$ application counted, and explicitly
charged spectral deflation of at most $\sqrt{\nu_n}$ atoms.  It does not cover
arbitrary adaptive or nonlinear response.  On the same path and parameter
scale, however, replacing exact full-vector output by the actual sparse PPR
residual certificate changes the answer completely: a five-coordinate,
degree-four supported polynomial has exact residual below
$\alpha/10$ and uses only constant charged work.  A fully charged five-row
append-only response returns the same sparse output.  Thus supported-prefix
polynomial generation alone does not imply product work; the literal exact-CG
cost comes from its Galerkin trajectory, not from the certificate or support
geometry by themselves.  Tightening the same certificate to
$\epsppr=1/(10n)$ forces every valid output to have full path support, but it
still does not restore product work: exact cancellations generate singleton
coordinate directions and a fixed spatial profile is synthesized in
$\Theta(n)$ fully charged recurrence work, matching an append-only response
up to constants while $\nu_{\rm fin}/\sqrt\alpha=\Theta(n^2)$.  The profile
synthesis is not a projected solve; any factor or graph-dependent inverse
used for coefficient synthesis remains response work.  No graph-uniform
$\Omega(1/(\varepsilon\sqrt\alpha))$ adjacency-query lower bound is claimed.
\end{abstract}
