\section{The classes are not one syntactic chain}
\label{sec:not-chain}

$\mathsf{MatRestrict}$ is a representation property and
$\mathsf{RowRec}[B_{\rm pre},B_{\rm resp},B_{\rm mem}]$ is an
arithmetic-generation family with explicit resource budgets.  An algorithm may
belong to both, one, or neither.  A response solver may use an iterative SDD
routine internally, and a Krylov implementation may materialize its complete
active vector every round.  The correct lower-bound statement therefore names
all restrictions it uses rather than relying on one family label.  The
endpoint-path task in \cref{thm:online-path-resource-separation} is identical
for both arms.  Its lower bound concerns only $C_{\rm mat}$ under
$\mathsf{MatRestrict}$'s exact full-current-vector invariant; it neither
bounds every resource coordinate of a materialized implementation nor changes
the shared reply/output request.

One useful capability diagram is
\[
 \mathsf{RowRec}[B_{\rm pre},B_{\rm resp},B_{\rm mem}]
 \subseteq\mathsf{Adj},
 \qquad
 \mathsf{Response}\subseteq\mathsf{Adj},
\]
with no claimed inclusion between the budgeted row-recurrence family and
$\mathsf{Response}$ until their preconditioner and memory clauses are fixed.
