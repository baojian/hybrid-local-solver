\subsection{A named certificate-level recurrence class}

Fix an endpoint-seeded unweighted path $P_n$, with ambient path degrees and
$n\geq8$, and set
\begin{equation}
 \alpha_n:=n^{-2},
 \qquad \epsppr:=\frac1{10},
 \qquad \nu_n:=\vol(V(P_n))=2(n-1).
 \label{eq:certificate-path-task-parameters}
\end{equation}
The common task $\mathcal T_n^{\rm cert}$ is to emit an explicit sparse list
$\widehat x$ whose unlisted coordinates are zero and for which an exact final
verifier confirms
\begin{equation}
 \norm{D^{-1/2}(b-Q_n\widehat x)}_\infty
 \leq \alpha_n\epsppr=\frac{\alpha_n}{10}.
 \label{eq:sparse-path-residual-task}
\end{equation}
There is one solve/output interaction.  The verifier recomputes the residual
on the emitted support and its exposed graph boundary; recursively maintained
residuals are not accepted without that pass.

\begin{definition}[Certificate-level supported-prefix polynomial class]
\label{def:cert-prefix-poly}
$\mathsf{CertPrefixPoly}$ contains deterministic exact-algebraic-cell
executions for this promised family with the following rules.

\begin{enumerate}[label=(\roman*)]
\item Numerical directions start from $b$ and are generated by charged
      applications of exposed rows of $Q_n$ and exact scalar linear
      combinations.  Polynomial coefficients may depend on $\alpha_n$ and on
      previously exposed exact scalars.  Scalar momentum, scalar restart,
      and exact scalar reorthogonalization are allowed.
\item A degree-$j$ direction is stored only on the reached prefix
      $[j+1]$.  The only mask is projection onto a reached prefix; arbitrary
      interior coordinate deletion is excluded.  Every exposed-row action,
      scalar/vector operation, and intermediate coordinate read or write is
      charged to $C_{\rm rec}$ or $C_{\rm mat}$ as appropriate.
\item Scalar diagonal maps are allowed.  This includes Jacobi scaling because
      $\diag(Q_n)=((1+\alpha_n)/2)I$.  Non-scalar diagonal maps,
      graph-dependent preconditioners, factors, Schur maps, rational inverse
      maps, and spectral atoms are excluded from this named recurrence class;
      thus $C_{\rm pre}=C_{\rm resp}=0$.
\item Adjacency labels are learned from the endpoint through the shared
      adjacency-list interface.  There is no seed-oblivious or graph-dependent
      preprocessing, and every degree/incidence reply, adaptive query batch,
      recurrence operation, state cell, scratch cell, verifier operation, and
      emitted cell is reported in \cref{eq:resource-vector}.
\item Exact algebraic cells are used throughout.  There is no randomness,
      failure probability, word/bit, finite-precision, or numerical-stability
      claim.  The only accepted output is the sparse list certified by
      \cref{eq:sparse-path-residual-task}.
\end{enumerate}
\end{definition}

This is a semantically explicit supported-growing-prefix polynomial subclass,
not the full $\mathsf{RowRec}$ framework.  In particular, it does not relabel
an append-only factor as recurrence work.  Conversely, its certificate task
does not require exact full-vector output.
