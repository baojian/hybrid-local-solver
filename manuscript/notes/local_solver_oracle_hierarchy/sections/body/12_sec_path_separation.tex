\section{A proved auxiliary path representation analogue}
\label{sec:path-separation}

The project's growing-active-set SDD audit supplies the cleanest separation.
There are endpoint-seeded paths on which the support-safe active trace visits
every prefix.  Any fresh full-vector representation pays quadratic writes by
\cref{lem:materialization}; more strongly, the exact-algebraic auxiliary
theorem \cref{thm:online-path-resource-separation} proves that even an in-place
exact materialization changes every old algebraic cell before the realized
stopping time.  On the identical query/reply task, one append-only tridiagonal
$LDL^\top$ response stores constant information per admitted vertex, evaluates
the next boundary value from its forward messages, and performs one final
reverse substitution.  Every displayed resource coordinate of this specified
response is linear in the stopping time except constant transient workspace.
For the materialized arm, only the intermediate-materialization coordinate is
bounded.

Within its exact-algebraic scope, this example proves:

\begin{enumerate}
\item the repeated-prefix bound is not information-theoretic;
\item warm starting an explicit vector is weaker than changing the
      representation;
\item an oracle lower bound that charges all resident coordinates every round
      excludes the directed-message algorithm by definition;
\item a universal lower bound must survive persistent elimination or explicitly
      forbid it.
\end{enumerate}

The response results on trees, cycles, bounded blocks, and equitable quotients
provide further examples.  They do not yet settle arbitrary nonequitable
cyclic cores.
