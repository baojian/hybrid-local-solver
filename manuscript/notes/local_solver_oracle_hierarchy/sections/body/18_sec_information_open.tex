\section{What remains genuinely open}
\label{sec:information-open}

The proved statements now support the following precise boundary.

\begin{enumerate}
\item Explicit output has tight worst-case complexity
      $\Theta(1/\epsppr)$.
\item Every currently analyzed path, spider, passive-trap, or disjoint-port
      construction collapses to $\widetilde O(1/\epsppr)$ one-pass exposure.
\item No graph-uniform $\widetilde O(1/\epsppr)$ adjacency-query algorithm is
      proved here.  Unknown completions can create many decoys, and an
      algorithm still needs a locally computable upper certificate proving
      that no unseen coordinate exceeds $\epsppr$.
\item The project product lower bound remains correct for its
      persistent-support one-hop oracle: it charges repeated resident volume,
      not discovery information.
\item A universal product lower bound would need either a counterexample to
      killed-influence packing or a hard family with essential global
      interference rather than independent passive corridors.
\end{enumerate}

One possible upper-bound program is a capacity-guided best-first exploration.
It would maintain a revealed subgraph and a rigorous envelope over all passive
unseen completions, expand the port of largest possible killed-Green
influence, and stop when every envelope falls below $\epsppr$.  Capacity
packing suggests output-linear total exposure.  Constructing an envelope
that remains valid under unknown cross-connections between boundary ports is
the central obstacle; until that certificate is proved, the proposal is an
algorithmic direction rather than a theorem.
