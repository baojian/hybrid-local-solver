\section{Target separation theorem}
\label{sec:target}

The recommended lower-bound program is not ``prove every local solver needs
$1/\sqrt\alpha$.''  It is the following quantified separation.

\begin{problem}[Recurrence versus response]
\label{prob:separation}
Fix explicit budgets in
$\mathsf{RowRec}[B_{\rm pre},B_{\rm resp},B_{\rm mem}]$, together with its
support, precision, row-action, and failure-probability clauses.  Construct one
graph family and one native accuracy regime for which:
\begin{enumerate}[label=(\roman*)]
\item every algorithm in that class uses
      $\widetilde\Omega(\nu_{\rm fin}/\sqrt\alpha)$ charged work;
\item a fully specified persistent-response algorithm uses
      $\widetilde O(\nu_{\rm fin})$ charged work;
\item both algorithms have the same adjacency interface, adaptive query task,
      native certificate, and final-output obligation;
\item the theorem states every coordinate of
      \cref{eq:resource-vector}, including preprocessing and peak memory, for
      both arms.
\end{enumerate}
\end{problem}

Here $\nu_{\rm fin}$ is the final charged degree volume from
\cref{eq:final-charged-volume}; it is not the vertex set $V$ or a proxy for
uncharged repeated work.  The exact-algebraic path theorem
\cref{thm:online-path-resource-separation} is only a weaker auxiliary
representation analogue.  It bounds $C_{\rm mat}$ for every materialized
implementation and gives the full vector only for one response
implementation; it does not close a representation-only version of
\cref{prob:separation}.  The desired computational separation remains open.
An endpoint path is unlikely to prove the strongest recurrence lower bound
once arbitrary Krylov directions are allowed.  Candidate harder families
should combine a slow spectral corridor with enough asymmetry or cyclic
response complexity to avoid a scalar quotient, while still admitting a
compressed response algorithm that can be analyzed exactly.
