\section{Conclusion}
\label{sec:conclusion}

Adjacency access is general enough to contain the project's local solvers, but
that generality is precisely why it does not by itself capture a first-order
condition-number barrier.  The lower-bound program should use adjacency access
as the ambient information model and add the weakest explicit computational
or representation restriction needed by the proof.  The most informative
proved universal statement is currently the tight
$\Theta(1/\epsppr)$ explicit-output bound.  Killed-capacity packing explains
why independent diffusion corridors cannot multiply this by
$1/\sqrt\alpha$.  At the computational level,
\cref{lem:free-preconditioner-collapse} proves that uncharged graph-dependent
inverse construction, encoding, and application cannot all be free in an
exposed-system recurrence-iteration lower bound.  The weaker auxiliary path
analogue \cref{thm:online-path-resource-separation} isolates only exact
intermediate materialization; it gives no precision-robust computational
separation.  The exact-CG counteralgorithm
\cref{thm:path-krylov-counteralgorithm} further defeats the fully exposed
endpoint-path product candidate when $n\ll1/\sqrt\alpha$.  For the analogous
fixed-support exact-system route with linear-cost matrix--vector access, it
leaves $n=\widetilde\Omega(1/\sqrt\alpha)$ as a necessary, not sufficient,
regime; it does not constrain every local support-discovery mechanism.
In that surviving regime,
\cref{thm:surviving-path-polynomial-obstruction} proves the matching
full-vector work obstruction only for the explicitly named diagonal,
polynomial, and charged spectral-deflation subclass.  It deliberately leaves
arbitrary nonlinear, adaptive, rational, and implicit response maps open.
For the actual sparse residual-certificate task on the same path,
\cref{thm:five-site-supported-prefix-counteralgorithm} gives a stronger stop
signal: a degree-four, five-coordinate polynomial and a fully charged
five-row response both succeed in constant exact-cell work.  Thus neither
support growth nor the ordinary-CG prefix trace can support the desired lower
bound.  Tightening the certificate to $1/(10n)$ removes the constant-prefix
output but not the broad recurrence escape:
\cref{thm:tight-certificate-sparse-basis-counteralgorithm} generates
singleton coordinate directions and a global certified profile in
$\Theta(n)=\Theta(\nu_{\rm fin})$ work, rather than the
$\Theta(n^2)$ product scale.  Any endpoint-path theorem must therefore impose
an independently motivated trajectory or materialization rule that excludes
exact sparse-basis cancellation, or change the same-task graph family.
None of these results proves the desired
$\nu_{\rm fin}/\sqrt\alpha$ row-recurrence lower bound.
The next information-level result should settle the killed-Green influence
conjecture; the next computational result should be a same-instance separation
between budgeted recurrent local span and fully charged persistent response,
not another lower bound for one named queue or handoff schedule.
