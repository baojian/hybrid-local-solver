\title{Hybrid Accelerated Local Solvers for Personalized PageRank\\
\large A Rigorous Technical Synthesis, Proof Audit, and TB-Science Task Specification}
\author{Baojian Zhou\\
\small Working research note for the \texttt{hybrid-local-solver} project}
\date{August 2026}

\begin{document}
\maketitle

\begin{abstract}
This note converts a sequence of research discussions into a self-contained,
claim-audited technical document.  It reviews the locally evolving set
framework and the Accelerated Evolving Set Process (AESP), formalizes a
proof-oriented hybrid that uses AESP as an early-stage accelerator and
Gauss--Seidel local SOR as a tail solver, and separates unconditional
convergence statements from conditional accelerated work bounds.  The main
rigorous conclusions are: (i) the AESP-to-LocSOR hybrid converges from every
finite handoff point; (ii) an objective-gap handoff gives a tail work bound
\(\mathcal O(1/(\sqrt{\alpha}\eps))\); and (iii) the full end-to-end bound
\(\softO(1/(\sqrt{\alpha}\eps))\) follows whenever the early AESP locality
factor is \(\mathcal O(1/\eps)\).  We also correct a previously misstated
weighted-\(\ell_1\) SOR range, derive an exact safeguard for over-relaxation,
and explain how the confinement machinery for \(\ell_1\)-regularized
PageRank suggests a route to the missing AESP locality lemma.  The final part
turns the research problem into an objectively verifiable Terminal-Bench
Science task whose official target is to improve a frozen AESP baseline on a
hidden suite, while retaining broader baseline comparisons for task-author
calibration.
\end{abstract}
