\section{Implementation blueprint}
\label{sec:implementation}

This section records the exact state transfer needed to keep theory and code
consistent.

\subsection{AESP state and the handoff}

At stage $t$, the inner queue is driven by $\nabla h_t$, but the final PageRank
certificate and both switch diagnostics use the original gradient $g=\nabla
f$.  Since
\begin{equation}
  \nabla h_t(x)
  =g(x)+\eta(x-y^{(t-1)}),
  \label{eq:inner-original-gradient}
\end{equation}
one may recover the original gradient locally by subtracting the proximal
term.  At the handoff:
\begin{enumerate}[label=(\roman*),leftmargin=2em]
  \item retain the selected checkpoint $x_J$;
  \item discard $y^{(J)}$, $x^{(J)}-x^{(J-1)}$, and all inner momentum/state;
  \item initialize $g_J=Qx_J-b$ or $q_J=D^{1/2}g_J$ exactly;
  \item enqueue precisely the coordinates satisfying
        $\abs{q_{J,u}}\geq\alpha\eps d_u$.
\end{enumerate}

The Work-I residual, if needed for a shared implementation, is
\begin{equation}
  \widehat r_J=-\frac{2}{1+\alpha}g_J.
  \label{eq:handoff-residual-conversion}
\end{equation}

\subsection{Queue update with shifted gradient storage}

If the tail stores $q=D^{1/2}g$, a safe $\omega=1$ push at active $u$ uses
$R=q_u$ and performs
\begin{align}
  x_u&\leftarrow x_u-\frac{2R}{(1+\alpha)\sqrt{d_u}},
  \label{eq:implementation-x}\\
  q_u&\leftarrow0,
  \label{eq:implementation-qu}\\
  q_v&\leftarrow q_v+\chi\frac{R}{d_u}
  \quad(v\sim u).
  \label{eq:implementation-qv}
\end{align}
After every changed coordinate, queue membership is tested against
$\abs{q_v}\geq\alpha\eps d_v$.  The pushed vertex is re-enqueued if its
retained residual is active; for $\omega=1$ it is zero immediately, but this
rule is required by a shared SOR implementation with $\omega\neq1$.

\subsection{Diagnostics to record}

Every run should record at least:
\begin{enumerate}[label=(\alph*),leftmargin=2em]
  \item graph, source, $\alpha$, final $\eps$, and code commit;
  \item the exact PageRank normalization and stopping certificate;
  \item per-stage AESP work, $\overline{\vol}(S_t)$, $\gamma_t$, and
        $\Lambda_t$;
  \item $f(x^{(t)})$ when an accurate reference value is available, the
        deterministic upper bound $U_t$, and $M(x^{(t)})$;
  \item switch stage, switch reason, and handoff checkpoint;
  \item tail work, maximum tail active volume, accepted/rejected safeguarded
        over-relaxation steps, and final certificate.
\end{enumerate}

\section{Experimental program suggested by the theory}
\label{sec:experiments}

The immediate experiments should be designed to test the proof bottleneck,
not merely the final wall-clock ranking.

\paragraph{Early locality profiles.}
For each graph and source, plot
$\vol(S_t^{(k)})$, $\overline{\vol}(S_t)$, $\gamma_t$, $\Lambda_t$, original
gradient mass $M(x^{(t)})$, and error against cumulative work.  This directly
tests whether the visually favorable part of Figure~4 coincides with
$\Lambda_t=\bigO(1/\eps)$.

\paragraph{Switch rules.}
Compare the deterministic objective rule \cref{eq:objective-switch}, the
residual-mass rule \cref{eq:mass-switch}, and an empirical marginal-gain rule.
All variants must return under the same final certificate.

\paragraph{Tail solvers.}
Compare safe $\omega=1$ LOCSOR, safeguarded $\omega_\star$, plain
$\omega_\star$, and a verified LOCCH block.  Report both work and the maximum
active-set volume so that a faster iteration count is not mistaken for local
work improvement.

\paragraph{Adversarial graph families.}
Include center- and leaf-seeded stars, paths, long spiders, and
core--boundary--exterior graphs.  These instances isolate residual-mass
settling, diffusive propagation, and high-degree transient activation.

\paragraph{Ablations.}
Measure the effect of AESP-LOCAPPR versus AESP-LOCGD, FIFO versus priority
selection, momentum restart, and exact versus adaptive inner certificates.

\section{Corrections and notation discipline}
\label{sec:corrections}

The following corrections are essential when this note is migrated into the
active paper or code.

\begin{enumerate}[leftmargin=2.2em]
  \item \textbf{Do not overload $C_t$.}  Use
        \[
          F_t:=f(x^{(t)})-f^\star,
          \qquad
          M_t:=\norm{D^{1/2}g(x^{(t)})}_1,
          \qquad
          \Lambda_t:=\overline{\vol}(S_t)/\gamma_t.
        \]
        A claim $M_t=\bigO(1/\eps)$ is not the locality bound needed for the
        total theorem.
  \item \textbf{Separate the SOR ranges.}  Global objective convergence holds
        for $0<\omega<2$.  Universal signed weighted-$\ell_1$ decrease holds
        only for $0<\omega<1+\alpha$.  The optimal parameter can lie outside
        that interval.
  \item \textbf{Use the original gradient for switching and final stopping.}
        The inner queue is driven by $\nabla h_t$; the PageRank certificate is
        driven by $g=\nabla f$.
  \item \textbf{Reset momentum at the handoff.}  Catalyst momentum cannot be
        reused as Chebyshev or SOR state.
  \item \textbf{Keep $q_{\rm cat}$ and $\sqrt{q_{\rm cat}}$ distinct.}
        Here $q_{\rm cat}=\alpha/(1-\alpha)$, while the accelerated scale is
        $\sqrt{\alpha/(1-\alpha)}$.
  \item \textbf{Use a product/log argument for sequential LOCAPPR.}  Per-update
        contractions multiply; replacing the product by an unqualified
        $1-\tau\sum_j\gamma_j$ expression can be invalid.
  \item \textbf{Do not import RPPR support results as unregularized AESP
        support theorems.}  The objectives and activation mechanisms differ.
\end{enumerate}
