## Direction handoffs

### Charged aggregate flushing and the sleep obstruction

The aggregate theorem is an exact-real implementation statement on one frozen
face `T=A dot-union F`, exposed cut `Q_WT`, and complete positive shifted
ladder. Additive nonnegative fragments are charged coordinate by coordinate:
`C_frag=sum_(j,l) nnz(d_j^(l))`. The scalar recurrence costs

`O_tilde_eta(cvol(T)/sqrt(alpha)+C_frag)`.

For `r` nonnegative columns, the authoritative matrix-product count is the
sum of the scalar counts over the `r` columns. For `r` signed columns, every
fragment is split before aggregation and `p=2r` certified nonnegative streams
are run with no pre-certification cancellation credit. The exact formulas are
`eq:aggregate-debt-multicolumn-products` and
`eq:aggregate-debt-signed-split`.

The energy certificate implies simultaneous *mathematical* one-sided exterior
intervals; it neither materializes an interval nor locates a violating label.
The explicitly non-output-sensitive `AllBoundaryFlush` scans and retains the
cut, processes the streams, contracts the cut, materializes and classifies all
interval endpoints, and emits every boundary interval plus a certificate per
output column. Its complete vector is

```text
(O(cvol(T)), O(1), I_frag+1, 0,
 O(C_frag+M_p+pJ+r|W|), O(M_p cvol(T)),
 O(r(e_partial(T)+|W|)),
 O(cvol(T)+C_frag+pJ+r|T|+|W|), O(|T|+|W|),
 O(M_p|T|+r(|T|+|W|)), Theta(r(|W|+1))).
```

Here `p=r` for nonnegative columns and `p=2r` after signed splitting, and
`M_p` is the actual total sparse-product count. The vector is stable label
`eq:aggregate-debt-eleven-vector` in the shared order
`(C_adj,R_adj,R_int,C_pre,C_ctl,C_rec,C_resp,M_pers,M_tmp,C_mat,C_emit)`.

At geometrically growing fixed-decision faces, one such flush per checkpoint
has recurrence-plus-fragment cost

`O_tilde_(eta,gamma)(p cvol(T_K)/sqrt(alpha)+C_frag^Sigma)`.

The full geometric vector `eq:geometric-aggregate-debt-eleven-vector` also
charges `I_frag^Sigma+K+1` interactions, all adjacency/cut rounds, the summed
cut response, peak retained debt and workspace, every full-face recurrence
write, interval materialization, and all emitted replies. The theorem does not
justify sleeping between checkpoints, permit online face/ladder mutation,
produce terminal RPPR/PPR output, or prove finite-precision or bit bounds.

More explicitly, with `W_rec=sum_k M_(p,k)cvol(T_k)`,
`W_mat=sum_k M_(p,k)|T_k|`, `W_Sigma=sum_k|W_k|`, and
`E_Sigma=sum_k e_partial(T_k)`, that vector is

```text
(O(cvol(T_K)), O(K+1), I_frag^Sigma+K+1, 0,
 O(C_frag^Sigma+sum_k M_(p,k)+pJ(K+1)+r W_Sigma),
 O(W_rec), O(r(E_Sigma+W_Sigma)),
 O(cvol(T_K)+C_frag^max+pJ+r|T_K|+max_k|W_k|),
 O(|T_K|+max_k|W_k|),
 O(W_mat+r sum_k(|T_k|+|W_k|)), Theta(r(W_Sigma+K+1))).
```

The canonical sleep obstruction uses ambient path degrees and chooses a
family-dependent `rho_n>0` after fixing `n`; no positive uniform lower bound is
asserted. The all-violations trace admits exactly one next path vertex at each
stage, while `cvol(S_(k+1))/cvol(S_k)=1+3/(2+3k)`. This is scheduling-only.
The exact-real append-only tridiagonal comparator has

```text
(Theta(n), n, n, 0, Theta(n), 0, Theta(n),
 Theta(n), O(1), 0, Theta(n)).
```

Thus `prop:singleton-path-geometric-sleep-obstruction` is not a path work,
adjacency-round, interaction-round, finite-precision, or PPR lower bound.

### Caterpillar Phase-I obstruction and one capped witness

For fixed `m>=2`, `0<alpha<1/2`, and
`0<rho<rho_can(m,alpha)`, validity plus finiteness of a composite burn-in
cannot bound `B_J^full`. From any reachable prefix before the first canonical
gate query, append any prescribed number `N` of exact-inner valid Catalyst
stages while the common checkpoint stays `Uhat_0={b_1}`. Each appended stage
adds at least constant control work, hence `Delta C_ctl=Omega(N)`. This is the
specification obstruction `prop:branch-caterpillar-uncapped-prefix-obstruction`,
not a lower bound for a capped policy.

The named `Full-BC-AESP_0` comparator pays one traversal of the promised
caterpillar, exposes the full fixed envelope `U=V=S*`, but retains only
`Uhat_0={b_1}` in the common canonical arena. Put

```text
C_* = 9m+1,                  V_* = 6m,
T_* = ceil(2 log(4)/sqrt(alpha/(1-alpha))),
D_* = C_* + T_* V_* L_*,    H_* = (1+log(2+C_*))D_*,
```

where `L_*` is the displayed exact relative-oracle logarithm in
`eq:branch-caterpillar-envelope-aesp-parameters`. It runs exactly `T_*`
reviewed relative-accuracy AESP-CD stages, commits no canonical batch, invokes
no response or external reply, and discards its proved numerical half-gap at
handoff. The complete prefix vector is

```text
(O(D_*), O(D_*), 0, O(C_*), O(H_*), O(D_*), 0,
 O(C_*), O(C_*), O(D_*), 0).
```

Therefore `B_env^full=O(H_*)=O_tilde(C(S*)/sqrt(alpha))`. Composing this
`k=0` prefix with the separately charged
`thm:branch-caterpillar-composite-response-handoff` returns exact RPPR output
with

`O(H_*+C_* log(2+C_*))=O_tilde(C(S*)/sqrt(alpha))`.

At the existing interface, additive and round coordinates sum exactly,
`R_int^total=m+1`, and releasing the numerical prefix arena leaves both total
memory peaks at `O(C(S*))`.

The soft order hides `log(1/(1-2alpha))` and is not uniform as `alpha` tends
to `1/2`; the exact multivariate bound is authoritative. This is a fixed-
family, full-envelope, zero-checkpoint, exact-real product witness. It is not
adaptive locality and proves nothing for an uncapped or automatically
exploring prefix, a nonzero checkpoint, another seed/range/policy/graph,
finite precision, bit complexity, graph-uniform work, or PPR accuracy.

### Moving-maximum path chronology

For the exact-real endpoint-path execution with `0<q<=1/4`,
`alpha=q^2`, and `rho=tau=q/5`, define

```text
E_gate(q) = q^12/[50(1+q^2)^2],
K_q = ceil(log(50(1+q^2)^2 q^-10)/[-log(1-q)]).
```

The transported energy is at most `q^2`. The normalized principal path
operator has infinity row norm at most one, which controls the full old-face
correction independently of the location or number of maximizer switches.
Once energy reaches `E_gate`, the safe-envelope error is at most
`q^3/5=alpha tau`; the complete gate either admits the immediate successor or
the global certificate holds. Hence each visited face survives at most
`K_q=O(q^-1 log(1/q))` fixed-face steps and

```text
T_q <= (J_q+1)K_q = O(q^-2 log(1/q)),
mathfrak V_(T_q) <= (5/q)T_q = O(q^-3 log(1/q)).
```

For the named internally gated literal full-prefix implementation with one
terminal external certificate/output return, the complete upper vector is

```text
(Theta(q^-1), Theta(q^-1), 1, 0,
 O(q^-3 log(1/q)), O(q^-3 log(1/q)), O(q^-3 log(1/q)),
 Theta(q^-1), O(q^-1), O(q^-3 log(1/q)), Theta(q^-1)).
```

This is `eq:path-moving-max-eleven-upper`. It supplies no matching
`Omega(q^-2)` stage or `Omega(q^-3)` swept lower bound, no logarithm removal,
no sampled `Theta` law, no product separation, no literal-zero-padding or
nonpath theorem, and no finite-precision or bit guarantee.
