## Direction handoffs

### Canonical active-relay chronology

For even `n>=4`, the simple unweighted graph has an anchor cycle `A`, one
degree-one petal `f_i` at each degree-four anchor `u_i`, the two-edge stem
`u_i-r_i-w_i`, and a perfect matching on `W`. Its degrees are `4,1,2,2`,
`cvol(V)=13n`, and both raw blocks `Q_AR` and `Q_RW` have rank `n`.

At any positive report-free canonical face and its next canonical
all-violations batch `B`, every nonseed relay obeys

```text
r_i in B  =>  f_i in U union B.
```

The relay threshold `x_u>4 alpha rho/vartheta` strictly exceeds the petal
threshold `x_u>2 alpha rho/vartheta`. Hence each nonseed relay is preceded or
co-admitted by its petal. A report-free face containing all relays already
contains at least `n-1` petals. Positive anchor and petal seeds have no
exception; one positive relay seed is the sole precedence exception; a
positive report seed violates the epoch immediately; every nonpositive seed
load gives the zero optimum. The positive-start ranges for seed types
`A,F,R,W` are respectively `rho<1/4`, `rho<1`, `rho<1/2`, and `rho<1/2`.

The theorem is only about the canonical all-violations trace. Under an
arbitrary positive-subset policy the petal is simultaneously eligible but may
be deferred. Paired petal--relay chronologies remain open. There is no
reporter, response-rank/work, finite-band, word/bit, finite-precision, or
numerical-stability lower bound.

The full prefix ledger is retained. In the shared order
`(C_adj,R_adj,R_int,C_pre,C_ctl,C_rec,C_resp,M_pers,M_tmp,C_mat,C_emit)`, fresh
validation of all local implications has incremental vector

```text
(Theta(n),1,0,0,Theta(n),0,0,0,O(1),0,0),
```

while reuse of already charged stored gadget records has

```text
(0,0,0,0,Theta(n),0,0,0,O(1),0,0).
```

Numerical face solves, response queries, state, recovery/materialization, and
required emitted labels remain representation-dependent additions. The next
candidate should give each still-exterior petal degree at least three---the
local relay-only window is
`(4 alpha rho/vartheta,6 alpha rho/vartheta]`---or feed relays from an
independent active backbone. Every seed orbit, report-quietness inequality, and
canonical batch must be reproved before reporter algebra.

### Fully charged double-Y handoff

On the unweighted double-Y with adjacent degree-three branch vertices, two
nonempty pendant arms at each branch, seed `s=e_o`, `alpha in (0,1)`, and
`rho in (0,1/3)`, a finite gate-compatible Phase-I prefix stores only its paid
irreversible branch bit and actual arm-prefix records as common support state.
Signed numerical and momentum state is retired. One charged outward pass
builds the exact affine records and the scalar core before `h` is admitted or
the fixed SPD rank-two Schur core afterward. The state depends only on the
committed support and does not replay the Phase-I order.

The prefix reports

```text
(C_adj^J,R_adj^J,R_int^J,C_pre^J,C_ctl^J,C_rec^J,C_resp^J,
 M_pers^J,M_tmp^J,C_mat^J,C_emit^J),
```

and, under the fixed exact-cell convention,

```text
B_J^full = C_adj^J + C_pre^J + C_ctl^J + C_rec^J
           + C_resp^J + C_mat^J + C_emit^J.
```

Rounds and memory peaks remain separate. If `J_post` is the actual number of
post-handoff expansion batches, the deliberately sequential post execution has

```text
(O(vol(S*)),O(|S*|),J_post+1,0,O(C(S*)),0,O(C(S*)),
 O(C(S*)),O(1),O(|S*|),|S*|+Theta(J_post+1)).
```

The `J_post+1` externally ordered gate stages each emit a constant-size
certificate reply. Recovery arithmetic is response work, the stored terminal
vector is materialization, and final solution cells are emitted separately.
Additive and round coordinates sum across prefix and post phases; retained
prefix storage gives `M_pers^J+O(C(S*))`, released-arena storage gives
`max{M_pers^J,O(C(S*))}`, and scratch gives `max{M_tmp^J,O(1)}`.

Unconditionally, total work is only `B_J^full+O(C(S*))=B_J^full+O(1/rho)`.
The product conclusion requires an independent
`B_J^full=O_tilde(C(S*)/sqrt(alpha))` theorem. The structural handoff is
exact-real RPPR for this branch seed and fixed core only. The particular
composite Catalyst/AESP prefix additionally requires `alpha<1/2`; growing
branch backbones, cycles, other seeds, finite precision/bit complexity,
numerical-energy carryover, and RPPR-to-PPR conversion remain open.

### Full-support path counteralgorithm

On the endpoint path `P_n`, `n>=8`, with ambient degrees,
`alpha_n=n^-2`, and `eps_ppr=1/(10n)`, the exact final verifier requires

```text
||D^(-1/2)(b-Q*x_hat)||_infinity <= alpha_n*eps_ppr.
```

Every accepted sparse list has all `n` coordinates, so
`nu_fin=2(n-1)`. Nevertheless, exact exposed-row actions and scalar
cancellations propagate singleton coordinate directions, and delayed scalar
combination with a universal fixed degree-six spatial profile produces a
strictly certified vector in linear work. The eleven-coordinate vectors are

```text
CertPrefixPoly: (Theta(n),n,1,0,Theta(n),Theta(n),0,
                 Theta(n),O(1),0,n),
same-task LDL:  (Theta(n),n,1,0,Theta(n),0,Theta(n),
                 Theta(n),O(1),0,n).
```

Both deterministic exact-algebraic-cell executions have `Theta(n)` nonmemory
work while `nu_fin/sqrt(alpha_n)=Theta(n^2)`. The profile combinations are
recurrence work; a projected tridiagonal solve, factor, Green formula, or other
graph-dependent inverse would be response work, but this counteralgorithm uses
none. The result is path- and class-specific. It does not shorten ordinary CG,
weaken the exact full-vector `DiagSpecPoly(r)` theorem, give finite-precision
robustness, or rule out a narrower independently motivated Galerkin,
trajectory, or materialization class or another graph family.
