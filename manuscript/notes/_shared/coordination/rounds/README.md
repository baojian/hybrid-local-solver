# Controller research-round ledger

This directory keeps the durable record of parallel direction cycles. It
answers four questions that chat history cannot answer reliably:

1. What exact question was assigned to each direction?
2. What evidence did the worker return?
3. Which conclusions did the controller accept, reject, or keep local?
4. Which other directions were told to act on the conclusion?

Create each record from [`../ROUND_TEMPLATE.md`](../ROUND_TEMPLATE.md). Use a
stable name of the form `YYYY-MM-DD-round-NNN.md`; never rewrite an older round
to make a later conclusion appear contemporaneous. If later work overturns a
round, add the superseding round and link both records.

The direction's `main.tex` remains proof authority, its `STATUS.md` remains the
live handoff, and [`../BROADCAST.md`](../BROADCAST.md) remains the current
cross-direction message. Round records are the audit trail connecting them.
