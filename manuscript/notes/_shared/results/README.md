## Common source facts

- The shared PageRank operator satisfies `alpha I <= Q <= I`.
- The RPPR minimizer is nonnegative and has
  `vol(supp(x*(rho))) <= 1 / rho`.
- A degree-normalized gradient certificate implies the note-scoped
  degree-normalized PPR solution bound stated in the shared problem contract.

See `manuscript/tex/shared/source_aligned_problem.tex` and the exact source
pointers in `docs/literature/acceleration.md`.

The main lower-bound frontier is to separate a budgeted row recurrence from a

## Promotion rule

A direction result enters this ledger only after its assumptions and proof
location are verified. It enters an active manuscript theorem only after its
dependencies are closed or the statement is explicitly narrowed to a correct
conditional/structural version. Measurements remain measurements, and
counterexamples remain attached to the exact algorithm or oracle they refute.
