\section{Conclusion}
\label{sec:signed-star-conclusion}

The center-star question now has a complete answer under a precise local
recurrence model.  Optimal signed SOR is a proved accelerated algorithm for
semantic PPR accuracy on that family, and its
$1/(\sqrt\alpha\varepsilon_{\rm ppr})$ work is optimal among dissipative
signed one-coordinate relaxations.  The proof is stronger than a numerical
fit: it supplies an exact error formula and a predetermined stopping time.

The comparison results explain why this success does not automatically
generalize:
\begin{itemize}[leftmargin=*]
\item nonnegative residuals are too restrictive and recover the
      $1/(\alpha\varepsilon)$ scale;
\item FISTA's extrapolation can be spectrally fast but locally expensive;
\item safe active-set acceleration can lose through repeated restarts;
\item a strong residual certificate can hide semantic cancellation;
\item output-scale elimination can beat coordinate lower bounds only because
      it is a stronger, separately charged inverse primitive.
\end{itemize}

Thus ``accelerated'' should never be inferred from iteration count alone.  A
publishable local-acceleration theorem must name the graph/access model,
semantic target, support trajectory, inverse primitive, stopping interface,
and every charged operation.  The star satisfies that checklist; the
graph-uniform target remains open.

\section*{Reproducibility note}

The companion script \texttt{verify\_star.py} uses exact rational arithmetic
on a grid of rational $t=\sqrt\alpha$ and dyadic tolerances.  It checks the
block recurrence, the semantic-error identity, the prescribed stopping
inequality, the star size bound, and the fast-mode cap used by the signed
lower bound.  The script
is a proof audit, not the source of any theorem.
