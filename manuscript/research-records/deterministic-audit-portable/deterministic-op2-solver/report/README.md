# Proof report

`deterministic_op2_audit.pdf` is the reviewed eleven-page report.
`deterministic_op2_audit.tex` is standalone TeX, with its package dependencies
listed at the top. Compile it twice with pdfLaTeX to resolve cross-references.
It does not require another research-workspace TeX file as an input.

The report credits the parallel core continuation proof and distinguishes
the independently developed practical refinements. The package-level
`VERIFICATION.md` and `PROOF_TO_CODE.md` give the test record and implementation
map. The research-duration ledger is separate from the mathematical proof.
