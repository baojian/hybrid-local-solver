# Manuscript working versions

This directory holds deliberately parallel manuscript versions that are not
registered as active research notes.

- `problem_definitions_v2/` is the user-owned working version.
- `../notes/problem_definitions/` remains the registered v1 reference until
  v2 is complete.
- No mathematical change flows automatically between the versions.
- After review, merge selected v1 material into v2, promote v2 to the
  registered note, and remove the obsolete v1 files.
