\begin{abstract}
We study single-source personalized PageRank on an undirected graph in a
fully charged adjacency-list model.  The main obstacle in using
$\ell_1$-regularized PageRank as a local support screen is not solving one
restricted system, but controlling how many growing restricted systems must
be rebuilt.  We reduce the regularized problem to a Stieltjes obstacle
problem and expose its exact grounded electrical-flow dual.  In this dual,
the obstacle slack is a vertex-constraint slack, so active-set expansion is
local dual constraint generation.  We prove that positive-residual batch
admissions are support-safe and that a threshold-batched sequence has only
$\widetilde O(1/\sqrt\alpha)$ relevant exposed faces.  The proof orders the
unknown optimal support by admission time and applies Chebyshev inverse decay
to a block-bidiagonal truncation of its Cholesky factor.

Combining this depth theorem with residual-certified, nearly-linear SDD face
solves yields an exact-real randomized algorithm with expected fully charged
work
\[
  \widetilde O\!\left(
    \frac{1}{\rho\sqrt\alpha}
    \log\frac1{\epsobj}\log\frac2\zeta
  \right)
\]
for an $\epsobj$-accurate regularized solution, with failure probability at
most $\zeta$.  A strict two-stage variant keeps only the discovered face and
then solves one ordinary principal PageRank system.  With
$\rho=\Theta(\epsppr)$ it returns a degree-normalized
$\epsppr$-accurate PPR vector in
$\widetilde O(1/(\epsppr\sqrt\alpha))$ expected work.  The outer support
construction and every accepted admission are deterministically certified;
randomness enters only through a standard supplied-face SDD solver.  We state
the point-source scope and the remaining deterministic finite-precision
question explicitly.
\end{abstract}
