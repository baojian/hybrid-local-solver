\begin{abstract}
Local PageRank algorithms seek sparse approximations with work bounds
independent of the graph size. Classical local push work bounds scale as
$1/\alpha$ in the teleportation parameter $\alpha$, but standard acceleration
can lose locality by activating high-degree vertices outside the optimal
support. We develop deterministic and randomized local algorithms for
$\ell_1$-regularized personalized PageRank with regularization parameter
$\rho$. By combining regularization continuation with constrained
acceleration, we control cumulative local work without requiring support
confinement. A complementary spectral argument bounds the number of
certified active-set expansions, yielding the randomized guarantee through
threshold batching. Both algorithms attain additive objective accuracy
$\epsobj$ in $\widetilde{\mathcal{O}}(1/(\rho\sqrt\alpha))$ local work
(in expectation for the randomized algorithm), with only polylogarithmic
dependence on $1/\epsobj$. Together, these results achieve the algorithmic
running-time target posed by Fountoulakis and Yang at COLT 2022.
\end{abstract}
